# Data Model: AI Test Design Assistance

## AiRun

Represents a server-side AI operation.

**Fields**

- `id`: UUID string.
- `organizationId`: owning organization.
- `projectId`: owning project.
- `userId`: initiating user.
- `feature`: enum-like value: `test_scenario_generation`, `test_case_generation`.
- `sourceArtifactType`: `business_rule` or `test_scenario`.
- `sourceArtifactId`: source artifact ID.
- `inputSummary`: minimal summary or reference; avoid storing unnecessary sensitive content.
- `estimatedCredits`: estimate shown before confirmation.
- `reservedCredits`: credits held before provider execution.
- `consumedCredits`: final consumed credits after success.
- `status`: `estimated`, `reserved`, `running`, `completed`, `failed`, `cancelled`.
- `failureCategory`: `none`, `validation`, `permission`, `insufficient_credits`, `provider`, `platform`, `output_validation`.
- `outputArtifactType`: `test_scenario`, `test_case`, or null.
- `outputArtifactIds`: one or more generated artifact IDs when successful.
- `createdAt`, `startedAt`, `completedAt`.

**Validation rules**

- `organizationId`, `projectId`, `userId`, `feature`, and source artifact reference are required.
- Final `completed` runs must have at least one output artifact and consumed credits.
- Provider/platform/output-validation failures must not have final consumed credits.
- Output references must belong to the same project and organization context.

**State transitions**

```text
estimated -> reserved -> running -> completed
estimated -> reserved -> running -> failed
estimated -> failed
reserved -> failed
```

## CreditTransaction

Represents auditable credit movement.

**Fields**

- `id`: UUID string.
- `organizationId`: owning organization.
- `userId`: initiating user when applicable.
- `aiRunId`: related AI run.
- `type`: `reserve`, `capture`, `release`, `refund`, `adjustment`.
- `amount`: positive integer credit amount.
- `reason`: concise reason for audit.
- `balanceAfter`: balance snapshot when balance is available.
- `createdAt`.

**Validation rules**

- Every reserve/capture/release tied to AI generation must reference an `aiRunId`.
- Capture amount cannot exceed reserved amount for the run.
- Release amount should equal unused reservation after platform/provider/output-validation failure.

## CreditBalance

Represents the organization's available AI credits.

**Fields**

- `organizationId`.
- `availableCredits`.
- `reservedCredits`.
- `updatedAt`.

**Validation rules**

- Available credits cannot become negative.
- A generation run cannot be reserved when available credits are lower than the estimate.

## BusinessRule

Source artifact for scenario generation.

**Fields used by this feature**

- `id`, `organizationId`, `projectId`, `moduleId`, `requirementId`.
- `title`, `ruleText`, `priority`, `status`.

**Relationships**

- One business rule can generate many test scenarios.

## TestScenario

Generated or existing test design artifact.

**Fields added or enforced by this feature**

- `id`, `organizationId`, `projectId`, `moduleId`, `requirementId`, `businessRuleId`.
- `title`, `description`, `scenarioType`, `priority`.
- `status`: include `draft`.
- `aiAssisted`: boolean.
- `aiRunId`: source AI run when generated by AI.
- `reviewedBy`, `reviewedAt`: empty until human review.
- `createdAt`, `updatedAt`.

**Validation rules**

- AI-generated scenarios must be `status=draft` and `aiAssisted=true`.
- AI-generated scenarios must link to the source business rule and AI run.

## TestCase

Generated or existing executable test artifact.

**Fields added or enforced by this feature**

- `id`, `organizationId`, `projectId`, `moduleId`, `requirementId`, `businessRuleId`, `scenarioId`.
- `title`, `preconditions`, `steps`, `expectedResult`, `testType`, `priority`.
- `status`: include `draft`.
- `aiAssisted`: boolean.
- `automationCandidate`: boolean or recommendation flag.
- `aiRunId`: source AI run when generated by AI.
- `reviewedBy`, `reviewedAt`: empty until human review.
- `createdAt`, `updatedAt`.

**Validation rules**

- AI-generated test cases must be `status=draft` and `aiAssisted=true`.
- AI-generated test cases must link to the source scenario and AI run.
- Steps must be structured enough for later manual execution.

## AuditLog

Represents sensitive action tracking.

**Events for this feature**

- `ai_run.estimated`
- `ai_run.started`
- `ai_run.completed`
- `ai_run.failed`
- `credits.reserved`
- `credits.captured`
- `credits.released`
- `artifact.ai_draft_created`

**Validation rules**

- Events must include organization, user, entity type, entity ID, and safe metadata.
- Metadata must not include provider API keys or raw sensitive provider payloads.
